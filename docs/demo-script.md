# 시연 순서

운영에서는 `DEMO_ENABLED=false`라 즉시 실행 버튼이 없습니다. 되묻기는 사진에 이야기가 저장될 때마다 자동으로 분석합니다.

## 준비

- 서로 다른 카카오 계정 2개를 씁니다. 같은 계정은 한 사람으로 처리됩니다.
- 방은 기본 마감(48시간)으로 만듭니다. 마감까지 24시간이 안 남으면 되묻기를 만들지 않으므로, 시연 전에 마감을 앞당기지 않습니다.
- Free 플랜은 재엮기 횟수 제한이 있으니 시연 전에 다 쓰지 않습니다.

## 되묻기가 잘 나오는 예시

1. 방장: 사진을 올리고 첫 한마디를 남깁니다. "황리단길에서 비 쏟아져서 우산 하나로 셋이 걸었어. 저녁은 칼국수 먹었고 민호가 제일 많이 젖었지."
2. 친구: 같은 사진에 덧붙입니다. "나는 저녁을 비빔밥 먹은 걸로 기억해. 서연이가 먼저 뛰자고 해서 다 같이 뛰었잖아."
3. 몇 초 뒤 알림과 모임방 홈에 질문이 나타납니다. 질문은 사람당 2개, 사진당 2개까지이고, AI가 물을 가치가 없다고 보면 나오지 않습니다.
4. 방장이 "먼저 엮기"를 누르면 두루마리가 만들어집니다.
5. 친구가 새 사실이 담긴 답가를 남기면 문단이 다시 엮입니다. 예: "그때 편의점에서 우비를 샀는데 바람에 바로 찢어졌어"

예시는 시연 전에 운영에서 한 번 돌려 봅니다. 재현 테스트: `AiFullFlowEvalTest`
